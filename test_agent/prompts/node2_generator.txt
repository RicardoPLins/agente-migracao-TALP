## Mocking rules:

### For urllib (original):
```python
from unittest.mock import patch, MagicMock

mock_response = MagicMock()
mock_response.read.return_value = json.dumps({"key": "value"}).encode()
mock_response.status = 200
mock_response.__enter__ = lambda s: s
mock_response.__exit__ = MagicMock(return_value=False)

with patch('urllib.request.urlopen', return_value=mock_response):
    result = original_module.some_function(...)
```

### For requests (migrated):
```python
import responses

@responses.activate
def test_something():
    responses.add(responses.GET, "https://api.example.com/endpoint",
                  json={"key": "value"}, status=200)
    result = migrated_module.some_function(...)
```

### For timeouts:
```python
# urllib
with patch('urllib.request.urlopen', side_effect=urllib.error.URLError("timed out")):
    ...

# requests  
with patch('requests.get', side_effect=requests.exceptions.Timeout()):
    ...
```

## Equivalence assertion pattern:
Every test MUST end with an equivalence check:
```python
# Primary: outputs must match
assert result_original == result_migrated

# Secondary: check specific fields that matter
assert result_original.get("status") == result_migrated.get("status")

# For exceptions: both must raise, same type or equivalent
with pytest.raises((OriginalError, MigratedError)):
    original_module.function(...)
with pytest.raises((OriginalError, MigratedError)):
    migrated_module.function(...)
```
